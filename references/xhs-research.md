# 小红书体验研究

小红书是可选软信号，用于理解近期体验，不负责确认开放、票务或路线硬事实。

## 适合研究

- 城市分区与游玩节奏；
- 拥挤、排队和建议到达时段；
- 拍照位置、天气体感和穿着建议；
- 近期施工、体验下降或常见踩雷；
- 餐厅氛围、分量和排队体验。

## 不应单独决定

- 是否营业或闭馆；
- 是否需要实名预约；
- 官方票价和退改规则；
- 公交末班、航班或铁路规则；
- 医疗、食品安全等高风险事实。

## 研究方法

1. 以“城市 + 月份/季节 + 主题”搜目的地信号；
2. 店级研究只针对已经通过位置和营业初筛的候选；
3. 优先近期内容，记录发布日期；
4. 至少比较多个独立内容，区分共识与个例；
5. 用官方/地图来源复核硬事实；
6. 把结论写成软信号，如“多篇近期笔记提到上午排队较短”。

## 输出建议

```json
  "checked_at": "2026-08-24"
}
```

## 不可用时

直接跳过并说明缺少近期用户体验信号。不要要求用户扫码登录，不要绕过验证码或访问限制，也不要把网页搜索摘要伪装成已读取帖子全文。
